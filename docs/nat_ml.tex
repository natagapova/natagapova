\cvsection{Избранные проекты}

\begin{cvproject}{Fair resume screening}{NLP · \href{https://github.com/natagapova/resume-screening}{GitHub} · \href{https://doi.org/10.66693/mathai.1017}{статья}}
BERT-классификатор резюме в 9 IT-суперкатегорий (HeadHunter). Integrated Gradients (Captum) для аудита bias; 39+ конфигураций debiasing. Baseline: 60.9\% accuracy, city-swap менял предсказание в 7.7\% пар. Data scrubbing: 0\% flip при 59.4\% accuracy.
\end{cvproject}

\begin{cvproject}{Emotion detection}{CV · FER2013 · on-device}
EmotionCNN: 58.7\% accuracy, macro-F1 0.569; до 60.8\% с ensemble+TTA. INT8-квантизация \textrightarrow{} Core ML и ONNX Runtime Web, latency 1.15\,ms. Полный цикл: данные, обучение, eval, деплой.
\end{cvproject}

\begin{cvproject}{Gesture input}{CV · MediaPipe · real-time}
Управление курсором жестами с веб-камеры: pinch / ready / click, PyAutoGUI, сглаживание, ~60 FPS. Rule-based классификатор поверх 21 landmark.
\end{cvproject}

\begin{cvproject}{Personal Knowledge System}{RAG · NLP · Python}
